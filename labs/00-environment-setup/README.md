# Environment Setup

Prepare the tools, access, and local configuration required for the workshop.

## Objectives

- Confirm the required software is installed.
- Clone and open the workshop repository.
- Create and activate the Python environment.
- Authenticate to Azure.
- Configure the required environment variables.
- Verify that the local environment is ready.

## Prerequisites

This section will document the required versions of Python, Visual Studio Code, Git, Azure CLI, and any workshop-specific extensions.

## Setup tasks

1. Verify required software.
2. Clone the student repository.
3. Create and activate the virtual environment.
4. Install project dependencies.
5. Authenticate to Azure.
6. Configure local environment values.
7. Run the prerequisite checks.
