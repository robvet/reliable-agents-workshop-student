# Lab 1: Application Overview

Explore the complete application before rebuilding any of its core behaviors.

## Learning objectives

- Explain the application's operational scenario and user experience.
- Follow a request through classification, reasoning, dispatch, and response assembly.
- Identify model calls, deterministic controls, and typed boundaries.
- Compare the read-only agent path with the deterministic write path.

## Lab activities

1. Explore each section of the user interface.
2. Submit representative asset-event prompts.
3. Follow each request in the Execution Trace.
4. Predict which agents an intent permits before reviewing the trace.
5. Trace one MCP and natural-language-to-SQL lookup.
6. Examine the separate outage lifecycle write path.
7. Complete the architecture knowledge check.

## Success criteria

- You can describe the end-to-end request path.
- You can identify where deterministic validation occurs.
- You can explain why agent reads and lifecycle writes use different paths.

## Code changes

None. This is an exploration and architecture lab.
