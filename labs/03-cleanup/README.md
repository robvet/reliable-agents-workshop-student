# Cleanup

Remove workshop resources and local configuration that are no longer required.

## Objectives

- Stop workshop processes.
- Remove billable Azure resources created for the workshop.
- Remove temporary credentials and local configuration safely.
- Preserve student work intentionally.

## Cleanup tasks

1. Save or commit any work you intend to keep.
2. Stop the frontend, backend, and MCP processes.
3. Delete workshop-specific Azure resources.
4. Verify that billable resources are gone.
5. Remove local environment files and temporary credentials as appropriate.
6. Confirm cleanup completion.

## Success criteria

- No workshop processes remain running.
- No unintended billable workshop resources remain deployed.
- Student source changes are retained or discarded intentionally.
