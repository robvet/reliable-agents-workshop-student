# Deployment

Deploy and verify the workshop application before beginning the hands-on labs.

## Objectives

- Provision or identify the required Azure resources.
- Configure the application for the workshop environment.
- Deploy the application components.
- Verify service health and connectivity.
- Establish a known-working application baseline.

## Deployment tasks

1. Confirm the target subscription and resource group.
2. Configure model deployments and PostgreSQL connectivity.
3. Deploy the backend and supporting services.
4. Configure and open the frontend.
5. Verify the health endpoints.
6. Submit one known-good request and confirm a complete response.

## Success criteria

- Required services report healthy status.
- The application loads successfully.
- A baseline request produces an intent, execution steps, and a final response.
