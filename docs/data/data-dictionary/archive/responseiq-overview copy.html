01 / The system

What AssetLens is

AssetLens combines model intelligence with deterministic control. Its orchestrator owns the workflow; specialist agents own domain work; validated Pydantic contracts connect every hop.

Operational AI, controlled by code

  • Natural-language interface for asset, event, crew, customer, and reliability questions.
  • Deterministic orchestration controls routing, plan validation, execution order, and fallbacks.
  • Structured contracts carry validated data from intent recognition through the final response.

A coordinated specialist team

  • One orchestrator classifies, plans, dispatches, and composes.
  • Five domain agents focus on topology, events, crews, customers, and reliability.
  • One data path reaches PostgreSQL through a separate MCP service with read-only controls.

02 / Supported today

Key use cases

Current capabilities center on asset-event awareness and response: understanding what happened, tracing impact, finding operational resources, and answering connected questions.

Event response

  • Identify and assess outages or asset events.
  • Summarize impact and current restoration context.
  • Connect event facts with affected infrastructure.

Asset topology and impact

  • Trace substation, feeder, and transformer relationships.
  • Locate assets on the operational map.
  • Follow affected network paths and connected locations.

Crew and situational awareness

  • Review crew availability and operating-region coverage.
  • Connect response needs with suitable operational resources.
  • Compare active events with available response capacity.

Reliability and recurring issues

  • Explore historical event patterns and repeat offenders.
  • Ask cause, duration, and performance questions.
  • Combine reliability history with asset and event context.

Customer status

  • Answer scoped service-impact and restoration questions.
  • Resolve location-oriented questions against operational records.
  • Keep customer workflows separated behind a dedicated specialist.

Cross-domain investigation

  • Coordinate several agents for one multi-part request.
  • Pass validated upstream results into dependent steps.
  • Return one coherent answer with a visible execution trace.

03 / Expansion path

Future use cases

The next evolution expands AssetLens from event restoration into a continuous health, event, response, and learning loop. These capabilities are direction, not current implementation.

Asset health monitoring

Ingest telemetry, maintenance history, and condition signals to calculate deterministic health scores.

Prediction and prevention

Detect deterioration, rank at-risk assets, and surface intervention opportunities before failure.

Meter and AMI integrity

Find silent meters, zero-usage behavior, missing readings, and measurement anomalies.

Load and capacity

Track loading, overload risk, rated capacity, thermal stress, and peak-load profiles.

Continuous learning loop

Feed event outcomes and maintenance history back into deterministic health and risk models.

Industry profiles

Adapt vocabulary, impact measures, and domain workflows across electric utility, oil, and gas operations.

04 / System flow

How it works

The live application turns a request into an authorized execution plan, runs the right specialists, and streams intent, agent steps, and the composed result back to the interface.

Understands and routes

  • Recognizes the request intent as a validated structured result.
  • Maps each intent to an allow-list of permitted specialist agents.
  • Supports focused questions and cross-domain requests involving several agents.

Plans and validates

  • Builds a typed execution plan with explicit steps and dependencies.
  • Applies seven deterministic checks before any agent can execute.
  • Rejects invalid, cyclic, oversized, or unauthorized plans without partial execution.

Queries operational data

  • Lets domain agents ask schema-independent, domain-language questions.
  • Uses MCP to generate, check, limit, and execute read-only SQL.
  • Loads asset coordinates through a direct validated SQL path for the operational map.

Explains and traces

  • Streams intent, specialist steps, and the final answer as they complete.
  • Composes agent results into a concise human-readable response.
  • Falls back safely when classification, planning, execution, or composition fails.
